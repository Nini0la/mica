# Official rules checked October 30, 2026

Source: https://nebiusglobalaihackathon.devpost.com/rules

- Submission period: **August 26, 2026, 09:00 Pacific → October 30, 2026, 10:00 Pacific**.
  The deadline is **17:00 UTC / 18:00 Africa/Lagos (WAT)** on October 30.
- Judging: **December 9, 2026, 09:00 Pacific → December 23, 2026, 12:00 Pacific**.
  The end is **20:00 UTC / 21:00 WAT** on December 23.
- A qualifying project uses at least one NVIDIA open-source model and runs on Token Factory
  or Nebius AI Cloud. The rules explicitly define a runtime call to the Token Factory inference
  API as satisfying the “runs on” requirement. Other application hosting is therefore compatible
  with this technical definition; Nebius compute hosting is not required for this implementation.
- Provide a working demo/test-build URL, English project description, public source repository,
  detectable open-source license, setup README and testing credentials where needed.
- Access must be free for judges through the end of judging.
- The video should be **less than three minutes**, show the project functioning, and be publicly
  visible on **YouTube**. Include its URL in the submission.
- Choose a track; the recommended fit for Mica is **Personal AI**.
- Describe significant eligibility-period updates to an existing project.
- Supply feedback on the Nebius/NVIDIA tools used.
- Best Use of Tavily requires a **functional runtime Tavily API call as part of the solution**.

Final submission, individual eligibility, ownership declarations and video publishing must be
completed by the entrant. This document records the rules checked, not an organizer's eligibility
approval. Submission details cannot be freely changed after the deadline under the published rules.
